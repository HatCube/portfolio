2.트러블슈팅
2-1.웹페이지 빌드가 되지 않는다는 문제
jekyll이 웹페이지를 못잡았다는것
원인을 살펴보니 web을 github actions로 해주니 해결

2-2.웹페이지 빌드 이후 페이지가 표기가 되지 않는다는 문제
이것은 의외로 간단했다.
처음 생성했을때 main.html로 작업했었는데 index.html로 변경해줘야 인식한다는 것
바로 파일 이름을 바꿔 주었다.

2-3.이미지 표기 불가
이미지 표기시 고정 위치로 잡은것이 문제
html을 수정하여 상대 경로로 수정 해주자 이미지가 정상적으로 표기되기 시작함
